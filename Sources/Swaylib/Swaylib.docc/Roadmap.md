# Roadmap

Where Swaylib is and where it is going. Finished items stay in their section, checked off.

## MVP

- [x] raylib built from source by SwiftPM on Linux, Windows and macOS, GLFW included.
- [x] Generator for enums, option sets and named colors from `raylib_api.json`.
- [x] Window, frame loop and the `Begin`/`End` scopes as closures.
- [x] Shapes, text, textures, render textures, images, fonts, shaders, 2D and 3D cameras.
- [x] Keyboard, mouse, gamepad, touch and gestures.
- [x] Sounds and music.
- [x] Unattended runs with `SWAYLIB_FRAMES` and `SWAYLIB_SCREENSHOT`.
- [x] Tests that draw into a render texture and check pixels, run under Xvfb on CI.
- [x] DocC documentation with a generated API coverage page.
- [ ] CI results on Windows and macOS confirmed green.

## Backends

- [x] `ANGLE` trait: raylib built for OpenGL ES 3 on an EGL context.
- [ ] Script that fetches prebuilt, checksummed ANGLE libraries for each platform.
- [ ] Choosing ANGLE's platform (Vulkan, D3D11, Metal) from Swift through GLFW's hint.
- [ ] ANGLE as the default on macOS.
- [ ] Render tests on ANGLE's SwiftShader backend, so Windows CI can run them too.
- [ ] raylib's software renderer (`rlsw`) and `PLATFORM_MEMORY` as a headless trait for CI.
- [ ] Zink: documented, tested setup on Mesa.

## Platforms

- [ ] Native Wayland on Linux (needs `wayland-scanner` output checked in or generated by a plugin).
- [ ] A person has run the examples on Windows and macOS.

## API coverage

- [ ] Models, meshes, materials and animations (`rmodels`).
- [ ] Audio streams and waves.
- [ ] The rest of `rshapes` (splines, collision helpers) and `rtext` (codepoints, glyph info).
- [ ] File system and file data helpers from `rcore`.
- [ ] `rlgl` for advanced users, in its own namespace.
- [ ] `Span`-based buffer APIs for texture and audio stream updates.

## Quality

- [ ] Reference image comparison for render tests, with a tolerance.
- [ ] More examples, ported from raylib's examples directory.
- [ ] Benchmarks of the Swift layer against calling the C API directly.
